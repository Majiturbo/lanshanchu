# 回答质量评测

用来量化两件事，分开统计，不合成一个分数：

- **引用可定位率**：回答里的每个角标，能否在来源里定位到对应的句子。由 `src/core/match.ts` 的字二元组重叠打分自动算，只能说明「最相关的一句在哪」，不能说明这句话支持结论。
- **引用支持率**：人工标注，逐条判断该来源的那句话是否真的支撑对应结论。标注三档：支撑 / 不支撑 / 无法判断。

## 怎么跑

1. 用 `eval/questions.md` 的 30 题，逐题在正式版客户端提问，保存：回答全文、来源列表、每个角标的对应来源。
2. 自动算可定位率：`match.ts` 对每个角标给出命中句子与分数，未命中记为失败。
3. 人工标注支持率：每题只看「结论句 ↔ 角标来源句」，不参考其他来源。
4. 记录单题耗时与首字时延，与上一版对比。

## 记录口径

| 指标 | 计算方式 | 当前状态 |
|---|---|---|
| 可定位率 | 命中角标数 / 全部角标数 | 待跑（历史单次观察：10/12，单一话题） |
| 支持率 | 标注为「支撑」的角标数 / 全部角标数 | 待跑 |
| 无法判断率 | 来源不可访问或表述含糊的比例 | 待跑 |
| 首字时延 / 整答时延 | 从提交到首字、到全部输出的时间 | 待跑 |

## 什么时候重跑

改提示词、换模型、调检索参数（查询词数量、读全文阈值、复查规则）之后，整套重跑一遍；只改 UI 不重跑。

## 已知局限

- 30 题不是随机抽样，只覆盖三类句式，不能代表全部用户问题。
- 支持率靠单人标注，没有交叉校验；标注者知道这是自己做的产品，存在偏向。
- 来源本身可能是二手转载，支持率只判断「来源支持结论」，不判断「来源是否可靠」。
